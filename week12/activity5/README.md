# Week 12 - Activity 5: Flask BMI Calculator

## Student

Han Jia

## Project

week12_activity5 BMI Calculator

## Description

This project is a simple Flask web application that calculates a user's Body Mass Index (BMI) based on their weight and height.

## Technologies Used

- Python 3.14
- Flask
- HTML

## How to Run

1. Activate the virtual environment:

```bash
source .venv/bin/activate
```

2. Run the application:

```bash
python app.py
```

3. Open your browser:

```
http://127.0.0.1:5005/
```

## Features

- Enter weight (kg)
- Enter height (m)
- Calculate BMI
- Display the BMI result
