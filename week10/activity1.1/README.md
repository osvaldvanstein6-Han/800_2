# Week 10 - Activity 1.1: Python Login & Signup System

## Project Overview

This project is a Python-only login and signup system. It uses a simple command-line interface and stores user data in a local JSON file. The system is designed to be maintainable, easy to read, and scalable for future improvement.

## Features

- Signup with full name, date of birth, email, password, and password confirmation
- Login with email and password
- Forgot Password with recovery code generation
- Reset Password using a recovery code
- View and update profile information after login

## Project Files

- `app.py` — application logic and command-line interface
- `users.json` — user data file generated automatically after signup
- `README.md` — project description and usage instructions

## How to Run

1. Open a terminal and navigate to `week10/activity1`
2. Run:

```bash
python3 app.py
```

3. Follow the menu options:
   - `Signup`
   - `Login`
   - `Forgot Password`
   - `Reset Password`
   - `Exit`

## Notes

- User data is saved in `users.json` for persistence.
- The system is implemented using only Python.
- The application uses modular functions for validation and user management.
